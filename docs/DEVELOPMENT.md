# Development guide

Everything about building, packaging and maintaining Subtitle Studio. User-facing documentation
lives in [README.md](../README.md) (English) and [README.zh-CN.md](../README.zh-CN.md) (中文).

## Project layout

```
main.py                  Entry point (GUI / CLI)
build.ps1                One-shot build: bundle → optional signing → MSI
app/
  config.py              Settings read/write (JSON in the user config dir)
  i18n.py                Locale loading and tr()
  locales/               UI strings (zh.json / en.json)
  core/
    env.py               yt-dlp / ffmpeg detection and bootstrapping
    subs.py              Subtitle parsing, sentence merging, timeline layout, output
    backends.py          Translation backends (Ollama / OpenAI-compatible) + autodetect
    pipeline.py          Job pipeline (Qt-free, testable on its own)
  ui/
    icon.py              Icon drawing, shared by exe / window / installer art
    theme.py             Dark theme and QSS
    widgets.py           Task card, drop zone, etc.
    settings.py          Settings dialog
    main_window.py       Main window
installer/
  Product.wxs            MSI definition
  build_msi.ps1          WiX compile (downloads the toolset on first run)
  sign.ps1               Authenticode signing (skips when no certificate is configured)
assets/                  Icons and installer art (generated by tools/make_*.py)
tools/                   Self-check, UI smoke test, i18n checker, icon generators
.github/workflows/       CI, build & release, locale checks
```

`app/core` does not import Qt, so `python tools/selfcheck.py` works without a display.
`python tools/smoke_ui.py` builds the whole UI offscreen and is what CI runs.

## Building

Requirements: Python 3.10+, `pip install -r requirements.txt pyinstaller`.

```powershell
.\build.ps1              # bundle + MSI
.\build.ps1 -SkipMsi     # portable folder only
.\build.ps1 -SkipApp     # MSI only (reuses dist/)
.\build.ps1 -Sign        # also sign (needs certificate env vars)
```

`assets/*.ico` / `*.bmp` are generated but committed, so a fresh clone builds without running the
generators. If they are missing, `build.ps1` regenerates them (`tools/make_icon.py`,
`tools/make_installer_art.py`).

> **Do not call PyInstaller by hand.** The plain `pyinstaller main.py` command omits
> `--add-data app\locales;app\locales` and the packaged UI then shows raw translation keys.
> `build.ps1` passes the right flags.

### Portable build

`dist/Subtitle Studio/` — copy the whole folder and run `Subtitle Studio.exe`. PyInstaller output is
still a native Qt app; no browser engine is involved.

### Windows installer (MSI)

- `ProductLanguage` is `1033` (English wizard), artwork by `assets/banner.bmp` / `assets/dialog.bmp`.
- Installs to `C:\Program Files\Subtitle Studio`, per-machine, with Start Menu and desktop shortcuts.
- `MajorUpgrade` with a fixed `UpgradeCode`, so newer versions replace older ones cleanly.
- Bundles ~107 MB of runtime — the target machine needs no Python.

`installer/build_msi.ps1` downloads the WiX 3.14 toolset from NuGet into `build/wix/` on first run
(~40 MB) and then runs `heat` → `candle` → `light`. It needs `dist/Subtitle Studio/` to exist.

Two gotchas that cost time before:

- Paths containing spaces must be quoted when passed to `candle`/`heat`. `-dSourceDir=$dist` silently
  breaks; write `-dSourceDir="$dist"`.
- Windows Installer draws each page's title text over the banner bitmap at roughly x 20–286 px, so
  the banner artwork must keep that area light and free of branding.

## Code signing

`installer/sign.ps1`, configured through environment variables:

| Variable | Meaning |
|---|---|
| `SIGN_PFX_PATH` + `SIGN_PFX_PASSWORD` | Use a `.pfx` file |
| `SIGN_CERT_THUMBPRINT` | Use a certificate in the local store (`/sm`) |
| `SIGN_TIMESTAMP_URL` | Optional, defaults to `http://timestamp.digicert.com` |

With no certificate configured the script prints a message and exits 0, so local builds are unaffected.

```powershell
$env:SIGN_PFX_PATH = "C:\keys\mycert.pfx"
$env:SIGN_PFX_PASSWORD = "..."
.\build.ps1 -Sign
```

**Order matters:** sign the exe → build the MSI → sign the MSI. The MSI re-packages the exe, so a
signature on `dist/` is not inherited. `build.ps1 -Sign` already does it in this order.

### Where to get a certificate

- **Free for open source** — [SignPath Foundation](https://signpath.io) signs qualifying OSS projects
  through a managed pipeline.
- **OV certificate** — roughly $150–300/year from DigiCert / Sectigo / GlobalSign. Since June 2023 the
  private key must live on an HSM or hardware token, so expect a USB dongle or a cloud signing service.
- **Azure Artifact Signing** (formerly Trusted Signing) — about $9.99/month, but individuals are only
  eligible in the US and Canada, organizations in the US / Canada / EU / UK.
- **EV certificates** no longer bypass SmartScreen (that changed in 2024) — the premium is not worth it
  just to avoid the warning.
- **Self-signed certificates** are for internal distribution only; they make things worse for public users.

All of the above still build reputation over time: a brand-new signed binary may warn on first
download until enough installs are seen.

## Continuous integration

| Workflow | Trigger | What it does |
|---|---|---|
| `ci.yml` | push / PR | Syntax check, locale consistency, offscreen UI smoke test |
| `build.yml` | `v*` tag or manual | Full Windows build, uploads MSI and portable folder, publishes a Release on tags |
| `i18n.yml` | changes to `app/locales/**` | Locale consistency only — no PySide6 install, a few seconds |

`build.yml` signs automatically when `SIGN_PFX_BASE64` and `SIGN_PFX_PASSWORD` secrets are present;
otherwise it produces an unsigned build.

Release flow:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

## Translations

UI strings live in `app/locales/<code>.json`:

```json
{
  "_language": { "code": "ja", "name": "日本語" },
  "strings": {
    "main.start": "翻訳",
    "main.tasks": "タスク"
  }
}
```

Adding a language takes three steps and **no code changes**:

1. Copy `app/locales/en.json` to `app/locales/ja.json`.
2. Change `code` / `name` under `_language`.
3. Translate the values in `strings`.

The app scans `app/locales/` at startup and adds the language to the interface-language dropdown.
Missing keys fall back to Chinese, so a partial translation is fine to submit.

Run the checker before opening a PR:

```bash
python tools/check_i18n.py --strict
```

It reports missing keys (with a completeness percentage), keys that no longer exist, keys used in
code but not defined, and **placeholder mismatches** — e.g. Chinese `翻译 {i}/{n}` against an English
string missing `{n}`, which would render literal braces at runtime.

## Two implementation notes

**1. Merge fragments into sentences before translating.**

YouTube ASR captions are chopped into 2–5 second pieces. Translating a fragment on its own produces
hallucinations:

| Input | Output |
|---|---|
| `really really long trunks` | "超长的树干" ❌ |
| `they have really... really really long trunks` | "他们的阴茎实在……长得超级长" ❌ |
| `...in front of the elephants. ...they have really really long trunks` | "这些大象…拥有极长的鼻子" ✅ |

So cues are merged until sentence-ending punctuation (treating `...` / `…` as a pause, not a
sentence end) with a minimum block length.

**2. Fetch subtitles through an explicit proxy, not TUN.**

TUN with fake-ip intermittently `RST`s or times out on Google traffic, while the HTTP proxy port is
stable. yt-dlp is therefore invoked with `--proxy` by default.

## Notes for the development machine

Environment quirks specific to the machine this was built on — not relevant to users or CI:

- `pip install` against PyPI sometimes dies with `SSL: DECRYPTION_FAILED_OR_BAD_RECORD_MAC`
  (a middlebox mangling large TLS transfers; `curl` is unaffected). Workaround: fetch the wheels with
  `curl` and install offline — see `wheels/fetch_wheels.ps1`.
- GitHub Releases downloads can stall at a few MB. WiX and other tools are therefore pulled from
  NuGet/CDN mirrors instead.
- Chrome's cookies cannot be read by yt-dlp here (`Failed to decrypt with DPAPI`); Firefox works.
